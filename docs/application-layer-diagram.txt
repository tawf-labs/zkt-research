                                     DATA FLOW SUMMARY
═══════════════════════════════════════════════════════════════════════════════════════════════

  A. PUBLIC DONATION
     UI → approve(IDRX) → ZKTCore.donate() → Escrow/Pool → ReceiptNFT.mint() → soulbound SBT

  B. PRIVATE DONATION (ZK)
     UI → Noir witness → bb prove → ZKTCore.donateZKPrivate(proof, inputs, nullifier)
       → HonkVerifier.verify() → NullifierRegistry.spend()
         → PrivateDonationPool.donatePrivately()
           → Event: (poolId, nullifier, commitment) — NO donor, NO amount

  C. GOVERNANCE
     UI → createProposal → castVote → finalizeVote → shariaReview → createPool → milestones

  D. SHARIA ZK AGGREGATION
     Coordinator ← council votes → quorum? → Groth16 prove → submitShariaReviewProof() → on-chain
